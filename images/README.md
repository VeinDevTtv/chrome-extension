# Icons Directory

This directory should contain the following icon files for the extension:

- `icon16.png` - 16x16 pixel icon
- `icon48.png` - 48x48 pixel icon
- `icon128.png` - 128x128 pixel icon

You can create these icons using any image editing software. They should be in PNG format.

The icons will be displayed in the Chrome browser's toolbar, extension management page, and during installation.

A recommended icon would be a Discord logo with a browser or website symbol overlay.
